# Data Structures and Algorithms

Start DSA after becoming comfortable with programming basics. Practise implementing each idea and explaining its time and space complexity.

## Suggested order

1. Time and space complexity
2. Arrays and strings
3. Linear search and binary search
4. Sorting — bubble, selection and insertion
5. Linked lists
6. Stacks and queues
7. Recursion
8. Hashing
9. Trees and binary search trees
10. Graph fundamentals

For every problem, record the question, your approach, code, test cases and complexity.
