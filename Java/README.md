# Java and Object-Oriented Programming

Use this folder for Java fundamentals and OOP practice.

## Suggested order

1. JDK, compiler and JVM basics
2. Your first Java program
3. Variables, data types and operators
4. Conditions and loops
5. Methods and arrays
6. Classes and objects
7. Constructors and encapsulation
8. Inheritance and polymorphism
9. Abstraction and interfaces
10. Exception handling and collections

## First exercise

Create a `Student` class with a name, roll number and a method that displays the student's details.
