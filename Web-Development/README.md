# Web Development

Build websites with the core web technologies.

## Suggested order

1. HTML document structure and semantic tags
2. Links, images, lists, tables and forms
3. CSS selectors, box model and typography
4. Flexbox and CSS Grid
5. Responsive layouts and media queries
6. JavaScript variables, functions and events
7. DOM manipulation
8. Fetching data from APIs
9. Accessibility and performance basics
10. Deploying a website

## First exercise

Create a one-page profile with a heading, an introduction, a list of skills and links to your projects.
