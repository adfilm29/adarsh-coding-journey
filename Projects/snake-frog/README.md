# Snake & Frog 🐍🐸

A responsive browser arcade game built with vanilla HTML, CSS, and JavaScript.

## Play locally
1. Download or clone this repository.
2. Open `Projects/snake-frog/index.html` in a modern browser.
3. Press **Start Game**.

No build tools, frameworks, or package installation required.

## Controls
- **Arrow keys** or **WASD**: move
- **Space**: pause / resume
- **R**: restart
- On mobile: use the on-screen direction pad

## Rules
- Collect glowing flies for 10 points each. Your snake grows each time.
- Avoid the moving frog, the walls, and your own tail.
- Difficulty changes the game speed.
- Your personal best is saved in your browser with localStorage.

## Project structure
- `index.html` — game layout and interface
- `style.css` — responsive visual design
- `game.js` — canvas rendering, movement, collisions, scoring, sound, and controls

Built with plain browser APIs. No external game engine.
