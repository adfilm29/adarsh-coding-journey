# Nawabi Safar — Lucknow Trip Planner

A responsive front-end website built with **HTML, CSS and vanilla JavaScript**. It lets visitors explore a curated list of Lucknow attractions and create a personal itinerary.

## Features
- Responsive landing page and destination cards
- Search by destination, category, neighbourhood or description
- Filters for Heritage, Culture, Nature and Shopping
- Add and remove places from a personal itinerary
- Estimated visit duration and illustrative entry-cost totals
- Compare selected estimates with a custom budget
- Save trip selections in browser local storage
- Copy an itinerary summary to the clipboard

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Search for a destination, add places to your safar, change the budget and save the itinerary.
4. Refresh the page to confirm that saved places remain available.

No backend, package installation, API key or database is required.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — destination data, search, filters, itinerary and local storage

## Accuracy note
This is a student learning prototype, not a live travel service. Entry-cost values are illustrative, not verified current ticket prices. The site does not provide live opening hours, restaurant availability, traffic, directions or bookings. Confirm current details with official sources before travelling.
