# Projects

This folder contains practical work built during the learning journey.

## Project ideas

- **Number guessing game** — practise conditions, loops and random numbers.
- **Student record manager** — practise data structures and file handling.
- **Personal portfolio** — practise HTML, CSS and JavaScript.
- **Expense tracker** — practise forms, validation and local storage.
- **Weather dashboard** — practise APIs and asynchronous JavaScript.

For each project, add a dedicated folder with its own README explaining the goal, features, setup instructions and what you learned.
