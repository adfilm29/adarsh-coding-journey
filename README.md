# Adarsh Coding Journey

A beginner-friendly learning workspace and personal coding portfolio. This repository tracks my progress as I learn programming, practise problem-solving and build projects.

## Learning roadmap

1. **C programming** — fundamentals, conditions, loops, functions, arrays and pointers.
2. **Python** — syntax, data structures, functions, files and automation.
3. **Java and OOP** — classes, objects and object-oriented programming.
4. **Data Structures and Algorithms** — arrays, strings, searching, sorting and problem solving.
5. **Web development** — HTML, CSS and JavaScript.
6. **Projects** — practical applications that bring the topics together.

## Repository structure

```text
C/                  C programming notes and exercises
Python/             Python notes and exercises
Java/               Java and OOP practice
DSA/                Data structures and algorithms
Web-Development/    HTML, CSS and JavaScript
Projects/           Practical projects
index.html          Coding journey dashboard
style.css           Dashboard styles
script.js           30-day practice tracker
```

## Run the dashboard

No installation is required.

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the roadmap and resources.
4. Tick a day in the 30-day tracker after a focused coding session.

The tracker saves progress in the current browser using local storage. Progress is not synced to GitHub.

## Learning rule

Understand the concept, write the code myself, test it with different inputs, and explain the solution in my own words.
